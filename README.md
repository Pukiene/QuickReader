# QuickReader

QuickReader is a .NET project. The `QuickReader.slnx` solution contains one project: `QuickReader/QuickReader.csproj`.

## Getting started

You’ll need the full project folder and a .NET SDK that supports the project’s target framework. Keep the `QuickReader` folder beside `QuickReader.slnx`.

Open `QuickReader.slnx` in Visual Studio or JetBrains Rider, or build it from the terminal. Run this command from the folder containing the solution:

```sh
dotnet build QuickReader.slnx
```

If the project is configured as an executable, run it with:

```sh
dotnet run --project QuickReader/QuickReader.csproj
```
